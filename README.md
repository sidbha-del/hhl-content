# hhl-content

Downloadable content packs for the HHL launcher (Hobbies and Habits Launcher): breathing techniques, interval routines and focus methods. The files are small JSON, written for HHL and released under CC0 1.0 (see LICENSE.txt).

`index.json` lists the packs with each file's size and sha256; the app checks both before it installs a pack. The app reads the `v1` tag.

Breathing, exercise and focus suggestions are general wellbeing ideas, not medical advice.
